# Envoy — 雷达显控终端

## 项目简介

**Envoy** 是一个基于 **Qt 5（C++17）** 开发的 Windows 桌面雷达显控终端（版本 1.0.0）。它通过 UDP 接收雷达设备输出的二进制协议数据，实时解析并以 PPI（平面位置显示）雷达图与目标列表的形式呈现，同时支持向雷达设备下发各类控制指令。

**核心用途**：作为雷达设备的通用显控/调试上位机，实现"接收 — 解析 — 显示 — 控制"的完整闭环，适用于雷达联调、外场观测与数据监视场景。

**主要功能**：

- **数据接收**：UDP 绑定本机地址端口，支持来源过滤（仅接收指定对端的数据包）与组播加入，接收缓冲区 1 MB。
- **协议解析**：识别 8 种下行数据帧（航迹、状态 1/2/3、过界、点迹、信处参数、数处配置），按 `#pragma pack(1)` 结构体解析并做累加和校验；未识别帧与非法来源包均有节流告警。
- **PPI 雷达图**：距离环、方位刻度与辐条、扫描扇区、过界波束光柱（最多 4 槽位）、目标点迹（驻留 3 s + 渐隐 5 s，去重后最多 2000 点）、目标航迹迹线；支持滚轮缩放、拖拽平移、单击选中目标、双击空白复位视图、悬停高亮。
- **目标列表**：编号、斜距、高度、方位、俯仰、幅度、信噪比、类型、置信度、跟踪次数共 10 列；列显隐与列宽可配置并持久化；支持"列表 / 凝视"两种视图模式（凝视模式查看单个目标的历史航迹点）。
- **参数控制**：开关机、8 种工作模式切换、阵地信息设置（偏北/俯仰/斜距修正、雷达经纬高）、扇区设置（0–3）、目标起批限制（速度/高度/距离上下限）、信处与数处参数查询；参数回传经范围校验后自动回填界面（`ConfigBackfill`）。
- **显示设置**：按目标类型（车辆、四旋翼、固定翼、鸟、船、行人、客机等 9 类）配置航迹颜色、绘制透明度与显隐。
- **日志记录**：带时间戳的运行日志，控制指令附 HEX 预览，最多保留 2000 行。
- **状态栏**：连接状态（空闲 / 已连接 / 失联及失联秒数）、遥测摘要、实时时钟，以及点迹显隐与右侧面板折叠快捷按钮。
- **应用外壳**：无边框深色主题窗口、自绘标题栏（最小化/最大化/关闭）、伪最大化与圆角、窗口几何与分栏布局持久化、单实例保护（QLockFile + QLocalServer）、HiDPI 适配。

## 协议帧类型

| 帧头 | 名称 | 方向 | 说明 |
| --- | --- | --- | --- |
| `0xCC5555CC` | 航迹 | 下行 | 目标航迹（位置、速度、类型、置信度等） |
| `0x55DDDD55` | 状态 1 | 下行 | 雷达工作状态与参数 |
| `0x19576492` | 状态 2 | 下行 | 显控/RTK/惯导/转台等状态（定长 420 B） |
| `0xCC1111CC` | 状态 3 | 下行 | 各分机故障与 GNSS 状态（定长 512 B） |
| `0x55CCCC55` | 过界 | 下行 | 波束方位角（机械/偏北，最多 4 波束） |
| `0xAA5555AA` | 点迹 | 下行 | 原始点迹（单帧最多 30 个点） |
| `0x55AAAA55` | 信处参数 | 下行 | 信号处理参数回传（查询响应） |
| `0x55222255` | 数处配置 | 下行 | 数据处理配置回传（查询响应） |
| `0x56482785` | 控制协议 | 上行 | 控制帧（功能号 + 数据块），用于开关机、模式、扇区、修正、起批限制、参数查询等 |
| `0xDD5555DD` | 控制回传 | 下行 | 控制协议回传帧头（常量预留） |

## 构建与运行

### 环境要求

- **Qt 5.12+**（模块：`core`、`gui`、`widgets`、`network`），推荐 Qt 5.12.x MinGW 64-bit
- 支持 qmake 的构建环境（Qt Creator 或命令行 MinGW/MSVC）；Windows 为主要目标平台

### 构建步骤

命令行方式（以 MinGW 为例）：

```bash
qmake Envoy.pro
mingw32-make -j4        # 或 make / nmake，视工具链而定
```

或在 Qt Creator 中打开 `Envoy.pro` 直接构建运行。

构建产物输出至 `Build/<debug|release>/bin/Envoy.exe`（工程文件中已配置 `DESTDIR`/`OBJECTS_DIR`/`MOC_DIR`/`RCC_DIR`）。运行时请确保 Qt 运行库（`Qt5Core.dll`、`Qt5Gui.dll`、`Qt5Widgets.dll`、`Qt5Network.dll` 等）可被找到。

### 运行时文件

| 文件/位置 | 说明 |
| --- | --- |
| `RadarConfig.ini`（exe 同目录） | 业务配置：`UIConfig`（扇区、修正值、雷达经纬高、起批限制）、`UDP`（本机/对端地址端口、来源过滤、组播）、`Display`（分类颜色/透明度/显隐）、`TableConfig`（目标列表列显隐与列宽）。数值以定点小数文本落盘，避免浮点精度漂移 |
| 注册表 `HKEY_CURRENT_USER\Software\RadarDemo\RadarDemo` | 窗口几何、最大化状态与分栏布局（Qt 默认 QSettings 位置） |

程序首次启动无配置时使用内置默认值（本机 `127.0.0.1:20001`，对端 `127.0.0.1:20000`）。

## 代码组织约定

- **Include/Src 分离**：头文件在 `Include/<模块>/`，实现在 `Src/<模块>/`，`INCLUDEPATH` 同时包含两者，源码统一以 `#include "Core/xxx.h"` 形式按模块路径引用。
- **模块划分**：
  - `App` — 应用装配与主窗口（帧分发、指令下发、界面编排）；
  - `Core` — 协议、配置、航迹存储与规则等纯逻辑，不依赖界面；
  - `Net` — UDP 收发封装；
  - `Ui` — 可复用界面组件（地图、表格、面板、弹窗、主题、窗口外壳）。
- **协议解析**：所有协议结构体使用 `#pragma pack(1)` 保证与线上字节流一致，解析前先做帧头与包长校验，包尾做累加和校验。
- **配置精度**：界面回显与落盘共用 `ConfigDecimals` 统一小数位数（角度 2 位、经纬度 6 位、距离/速度 2 位），以定点字符串写入 INI。
- **国际化**：用户可见文本均经 `QObject::tr()` 包裹，界面语言为简体中文。
